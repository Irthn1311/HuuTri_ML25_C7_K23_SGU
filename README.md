## 📊 Các dự án nổi bật

### 1. **Titanic Survival Prediction** 🚢
- **Mục tiêu**: Dự đoán khả năng sống sót của hành khách Titanic
- **Dataset**: 891 hành khách với 12 features
- **Kỹ thuật**: Feature Engineering, Ensemble Methods, Cross-validation
- **Kết quả**: Đạt accuracy > 0.81
- **Files chính**: `titanic_improved_0.81_approach.ipynb`

### 2. **Iris Flower Classification** 🌸
- **Mục tiêu**: Phân loại 3 loài hoa Iris dựa trên 4 đặc trưng
- **Dataset**: 150 mẫu hoa (50 mỗi loài)
- **Kỹ thuật**: EDA, Data Preprocessing, Multiple ML Algorithms
- **Kết quả**: Đạt accuracy > 0.95 với LDA
- **Files chính**: `baiDiemCong/ex01_iris_classification/`

### 3. **Diabetes Prediction** 🏥
- **Mục tiêu**: Dự đoán bệnh tiểu đường dựa trên các chỉ số y tế
- **Dataset**: 768 bệnh nhân với 8 features
- **Kỹ thuật**: EDA chi tiết, Outlier Detection, Statistical Analysis
- **Files chính**: `Tuan3/EDAPimaIndia/EDA_HuuTri.ipynb`

### 4. **Wine Quality Analysis** 🍷
- **Mục tiêu**: Phân tích chất lượng rượu vang đỏ
- **Dataset**: 1599 mẫu rượu với 11 features
- **Kỹ thuật**: Descriptive Statistics, Correlation Analysis, Distribution Analysis
- **Files chính**: `Tuan4_Lab5/113_winequality_red.ipynb`
