# Machine Learning Coursework & Experiments

A public archive of my Machine Learning coursework, notebooks, small projects, and competition-style experiments at Saigon University.

This repository is a **learning archive**, not a single production project. For larger end-to-end work, see the selected projects on my GitHub profile.

## What is inside

The repository records progression from introductory Python and EDA to model evaluation, feature engineering, structured ML projects, and small Kaggle-style challenges.

### Topics covered

- Python for data analysis
- pandas and NumPy
- exploratory data analysis
- visualization
- preprocessing and feature engineering
- supervised learning
- cross-validation and hold-out evaluation
- ensemble methods
- experiment organization
- introductory competition workflows

## Notes on results

Numbers inside individual notebooks reflect the protocol used by that exercise. They should not be interpreted as directly comparable benchmarks across datasets or projects.

When reusing an experiment, check its exact split, preprocessing, leakage controls, validation procedure, and random seed before relying on the reported metric.

## Why this repository stays public

It documents the learning process behind later AI / computer-vision work and shows how the project structure evolved over time. It intentionally contains both early exercises and more organized experiments.

For portfolio review, the best starting points are the more recent standalone repositories rather than treating every notebook here as a finished project.
